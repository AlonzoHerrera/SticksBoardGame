Context:

Request:
Create a Random Easy AI strategy for the Flutter Game B project.

The AI should randomly choose a move for the current player.

- Create a RandomEasyStrategy class.

- The AI should work with the current Game engine.
- Use Dart.
- Keep the AI code separate from the Flutter user interface.

Output:
Provide the complete Dart code for:
- game_move.dart
- ai_strategy.dart
- random_easy_strategy.dart
